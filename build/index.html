Sensor calibration

Capture an averaged reading for each end of the scale.

  1. Let the probe settle in dry air or your dry reference medium. Capture dry.
  2. Place the sensing area in your wet reference medium, keeping electronics dry. Capture wet.
  3. Each capture takes about 10 seconds. A large spread suggests the probe needs more time to settle.

Garden configuration Zone settings, wiring and connectivity
Zones Map a sensor channel to one or more valves. Changes apply live.

Channels 0–3 use board 1, 4–7 board 2, 8–11 board 3, and 12–15 board 4. Boards share the same I²C bus.

Valve configuration GPIO assignments and valve polarity. Saving restarts the controller.

Volume mode and flow meter settings are reserved for future pulse counting. All watering is timed and bounded by the hard cutoff.

I²C and hardware Shared bus pins, ADS1115 addresses and optional rain input

Use addresses 0x48–0x4B. Match each board’s ADDR wiring. Exactly one set of bus pull-ups is recommended.
